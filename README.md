# 医学人文交流活动的主题组合与后续转化

这是医学人文教学资料的本地分析工作区。医学人文交流活动议题、参与和后续跟进记录，均为虚构演练资料。

## 资料

`data/symposium-followups.csv` 是 UTF-8 编码的合成演练表。活动议题可以由多所院校及多个学科共同提出；跟进状态需有单独证据。

字段含义：活动代号、议题代号、院校、学科、日期、参与人数、跟进类型、跟进状态、证据引用。

表中代号只用于连接同一份演练资料，不对应真实人员、院校或患者。数据没有预先计算的统计结论。

## 运行

需要 Python 3.11 或更高版本，无第三方依赖。运行基线检查：

```sh
python3 -m unittest discover -s tests -v
```

`src/humanities_analytics/inputs.py` 提供通用 CSV 读取入口，将每行作为字符串字段返回。
